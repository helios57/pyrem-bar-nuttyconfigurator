# 🔗 NuttyB Configurator Related Resources

## 🎮 Game Widgets

To install these widgets, download the raw `.lua` files and place them in your game's `Widgets` directory: 
`\Beyond-All-Reason\data\LuaUI\Widgets` (Create the folder if it doesn't exist).
When playing, press the widgets hotkey (usually `F11`) to enable them in-game.

*   **[Raptor Stats Panel with Aggro](https://gist.github.com/tetrisface/2f99f5a5b179e3ac42e7e63825880713)**: Replaces stock Raptor Stats widget. Exhibits extended aggression insights and queen resistances.
*   **[Map Start Lines Widget](https://gist.github.com/rcorex/15ac19cad881b85d2d1e8c1f482b9525)**: Evaluates and draws optimal start lines for a 12-player vs Raptors ecosystem on the Full Metal Plate map.
*   **[Layout Planner Widget](https://github.com/noryon/BARLayoutPlanner)**: Visualizes and draws structural lines for intricate base layout planning.
*   **[Reclaim Selected Widget](https://github.com/manshanko/bar-widgets/blob/main/cmd_reclaim_selected.lua)**: Binds a button to reclaim selected units utilizing nearby nano turrets. Excellent for clearing old wind turbines on the fly.
